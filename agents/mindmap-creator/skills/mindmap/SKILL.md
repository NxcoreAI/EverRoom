# 生成思维导图

步骤：

1. 通读 `content`，列出材料真实讨论的主要主题板块（目标 4-8 个），互相不重叠、合起来覆盖全篇。
2. 为每个板块起短语标签（≤40 字符）；板块内能分出有意义的子概念时加一层，最多到第三层；材料扁平就停在第一层。
3. 根 `topic` 用整套材料的浓缩短语，优先沿用标题微缩。
4. 自检清单：分支数 3-8；含根总层级 ≤3；所有标签是短语且 ≤40 字符；没有材料外的内容；room scope 下跨文档重复主题已合并。
5. 调用 `subagent_submit_result` 提交 `{ topic, branches, digest }`。
