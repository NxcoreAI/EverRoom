# AI 味校准清单（二级）

两段使用：定调写完设计简报后过第一段（不通过就推翻重定，改的是简报不是页面）；全部页生成完、提交前过第二段（发现问题的页用 `context_room_slides_set_page` 重生成）。

## 第一段·定调自查

- **换题材测试**：把这套色板+母题+节奏换到一个完全无关的题材上还成立吗？成立 = 定调失败，重定。
- 色板是不是「深底 + 电蓝/紫蓝」？这是最大众的 AI 默认，除非题材真的属于海洋/航空/科技深空，否则重选。
- 母题是不是「色条 / 角标 / 角落装饰 / 短横线」？这些是装饰不是母题，重选。
- 六个颜色齐了吗？只定了主色 = 还没定调，按 palettes.md 配方补齐。

## 第二段·完稿逐页扫描

**版式 AI 味**（出现即重生成该页）：

- 标题下划线、标题前小竖条、卡片左缘色条、卡片顶部色条——层级用底色/字重/字号表达
- 用 ◆ ● • ▸ 等符号字符手拼列表符号（列表符号只能来自 bullet:true，✓✗★只许在表格单元格）
- 标题框高按一行估算但文字折成两行（对照折行速查表数标题字数，超行就缩字号或加高框）
- 三张以上一模一样的卡片平铺（同圆角、同阴影、同结构），或全篇多数页都是「色块+粗标题+描述」
- 「圆角+阴影+浅底」三件套卡片同页出现两处以上 = SaaS 后台感；结论面板改直角扁平面板（无圆角无阴影），靠字号与主色数字立层级
- 大数字页排成 2×2 机械等分、或焦点数字与从属数字挤在同一字号带 = 没有焦点；改「左半面板超大焦点数字（≥2 倍于从属字号）+ 右侧竖排从属项」
- 内容不是序列却排了 01/02/03 编号
- 角落装饰块、零散短线、无来由的几何图形
- 多个并列对象各配一色（彩虹卡片）
- 居中排版的正文（正文左对齐；只有封面/章节/金句可以居中）
- 没有素材硬凑假图占位

**色彩 AI 味**：

- 跨色相渐变（紫→蓝、青→粉）
- 强调色一页用了两处以上，或全篇强调色到处都是
- 出现了六色角色之外的颜色
- 深底页文字只有一档白（应有三档：100%/80%/60%）

**节奏 AI 味**：

- 相邻两页同一个布局预设；连续三页同一种卡片阵
- 全篇全是重页没有轻页（或反之），没有 3~4 页一次的呼吸
- 母题在某几页消失了，或某页母题喧宾夺主盖过内容

**收尾**：

- 每页过一遍 3 秒测试：一眼能说出这页的一句话结论吗？
- 每页问一遍「能不能删掉一个装饰」——能删就删（提交前删一件配饰原则）。
