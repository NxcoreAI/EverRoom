# 色板工艺（二级）

## 六色角色制

设计简报的色板永远是六个角色，缺一不可：**深底**（封面/章节/封底背景）· **主色**（标题、结构元素、图表第一系列，约 30% 视觉权重）· **辅色**（次级结构、图表第二系列）· **强调色**（焦点数据、关键数字，≤10%）· **浅底**（内容页背景）· **正文色**（浅底页文字）。浅底页配比 60/30/10：浅底 60、主+辅 30、强调 10。

## 品牌色推导配方（instruction 带品牌色或题材与风格默认色板冲突时用）

给定一个品牌 hex，按序推导全套六色，**禁止只换主色不调全套**：

1. **主色** = 品牌色本身；饱和度过高时先降（HSL 的 S 压到 ≤65%），艳色整篇用会显廉价。
2. **深底** = 同色相、L 压到 10~16%（如绿 #2F9E44 → #14281C）。
3. **辅色** = 同色相 S−25%、L+15~20%（绿例 → #7FB389）；或色相 ±20° 的邻位。
4. **强调色** = 与主色互补（色环对角）或跨 150~180° 的高饱和色；拿不准时暖金 #C9A227 是安全兜底（与几乎所有中低饱和主色相配）。
5. **浅底** = 主色铺白的近白（等价主色 L≥96%，如 #F4F8F4），或中性 #F6F7F9。
6. **正文色** = 浅底页用深底色或近黑带主色相（绿例 #22301F）；深底页用 #FFFFFF（标题）/ #FFFFFFCC（正文）/ #FFFFFF99（eyebrow）三档白。

推导完验算三件事：浅底页 60/30/10 成立；强调色在浅底与深底上都够对比度；图表系列色能用主→辅的深浅梯度凑满 ≤4 个。

## 色彩纪律

- 全篇色数 ≤6（六色角色之外不允许出现新颜色）；强调色只给焦点与关键数据，一页最多一个强调点。
- 禁纯黑 #000000 与纯灰 #808080——所有中性灰带一点主色色相（主色蓝 → 灰偏 #6B7280 这类冷灰）。
- 渐变只允许同族深浅：主色↔深底、主色↔辅色；禁跨色相渐变（紫→蓝、青→粉是 AI 味重灾区）。
- 图表系列色从主→辅取深浅梯度，≤4 个系列；单系列一律主色。堆叠图（barStacked）相邻系列明度差拉到 ≥18%（同色系靠明度分段，别靠色相微调），主角系列拿主色且排在最底，其余按深↔浅交替排——投影仪和打印会把明度差小于 15% 的两段洗成一片。
- 深底页强调色允许加亮（L+15%）保对比；浅底页强调色用原值。
