# 设计工艺技能（一级总纲·定调层）

分工：风格技能定字级与版式语言，布局技能定每页结构与坐标，**本技能定这份 deck 的设计身份**——它为什么长这样、而不是任何别的 deck 长这样。用法：create 第 1 步先读本文件做定调、写设计简报，再选风格与版式；全部页生成完、提交前读 `references/ai-tells.md` 做完稿自检。

核心判断：**「选一个风格模板填内容」就是 AI 味的根源。** 七个风格技能是底子不是答案——同一风格的两份 deck，一份好看一份平庸，差别在于是否为这个题材做了具体的设计决定。

## 定调三步（产出设计简报，5 行以内）

1. **三问**：这门生意的材质与行业语言是什么（产品、空间、材料、数据形态）？给谁看、在什么场合？希望对方看完记住哪一件事？
2. **从主题推导视觉方向**：题材 → 色相家族与温度（深海养殖→冷蓝绿；精品咖啡→暖褐；儿科→暖陶白；工业制造→石墨+信号色）→ 深浅结构 → 母题候选。判断标准：**把这套视觉方向换到一个完全无关的题材上还成立吗？成立 = 不够具体，推翻重定。**
3. **写设计简报**（定稿后全篇严格遵守）：
   - 色板：深底 / 主色 / 辅色 / 强调 / 浅底 / 正文 六色全 hex（默认取所选风格文件；品牌色或题材冲突时读 `references/palettes.md` 按配方推导整套，禁止只换主色不调全套）
   - 母题：一句话（见下）
   - 明暗节奏：哪些页深底、哪些页浅底
   - 密度基调：重页/轻页怎么交替
   - 字体角色：全篇 ≤2 族（标题/正文同族分字重，或衬线只给金句与引言）

## 视觉母题（designed 与 templated 的分水岭）

全篇一个母题，每页至少出现一次；母题必须从主题语言里来，不许是无来由的装饰。

**母题构造公式 = 基础元素 × 处理方式**，从主题语言选基础元素（数字/图标/线条/色块/图片框/引号），再选处理方式（超大/半透明 ghost/反白/圆底/非对称比例）：

- 数据感题材 → 超大 ghost 数字（100pt 级、alpha 10~18 同色系，放空白区、数组首位先画；框宽 ≥ 字数×sizePt×0.8+40px——窄了数字会折行成「180/0」，这是 ghost 最常见的翻车点）
- 图标感题材 → 圆底图标（icon 压在同色系浅底 ellipse 上，全篇同一尺寸）
- 编辑感题材 → 关键词反白块（重点词压主色 rect 内白字，只给每页一个词）
- 结构感题材 → 固定非对称分栏比（如 7:5，全篇同一组竖线）
- 人文题材 → 超大引号 / 圆角图片框（全篇统一圆角与描边）

母题变奏：封面强（大面积/加强版）、章节页中、内容页弱（点缀存在感）。**反母题**（这些当母题 = AI 味）：色条、角标、角落装饰块、零散短线、每页左上角同一个小图标。

## 明暗三明治节奏

深底（封面）→ 浅底（内容）→ 深底（章节页，全篇 ≤2）→ 浅底（内容）→ 深底（封底）。全篇深底也成立（高级感路线），但要求深底色全篇统一、浅色文字层级拉开三档。内容页之间用重/轻交替换气：图表页、表格页（重）后面接大数字页、金句页（轻），每 3~4 页一次呼吸。

## 焦点纪律（每一页）

- 一页一个焦点：主元素占内容区 ≥50% 面积，或拿走全页最强字重/最大字号；其余全部从属。
- **大胆预算**：每页只在一个地方花大胆（超大字/满幅色块/满幅图/ghost 大数字），其余保持安静——全页都是重点 = 没有重点。完稿前问一遍：这页能不能再删掉一个装饰？
- 3 秒测试：一眼扫过要能说出这页的一句话结论——结论写进行动标题，不靠图注和小字。

## 内容先于版式（选布局预设之前先问）

- 单个关键数字 → 80pt 大数字 + 小标签，不画图表
- 趋势/对比 ≥3 个数据点 → chart
- 金句/宣言/证言 → 引用页，不塞进要点列表
- 只有内容真是序列（步骤/里程碑/流程）才用 01/02/03 编号——编号不是万能装饰
- 一个论点 + 证据 → 左论点右图表；三个并列理由才用三卡片，且卡片必须等宽等高、内容真实等价

## 节奏纪律

相邻页不用同一预设；连续三页不出现同一种卡片阵；图表页后不接图表页。全篇页数与页序节奏按布局技能 SKILL.md 执行。

## 完稿自检
