# 软 3D 黏土（Soft 3D Clay · 圆润）

一句话身份：高级玩具店橱窗——暖米色空间里漂着几件圆润的哑光形体，柔和的影子让它们像黏土捏出来的，信息版面却干净得像 UI 设计规范。现代、轻盈、治愈，但绝不幼稚。引擎没有真 3D，本风格的「黏土感」由**圆角 + 分层 + 柔和阴影**三件事合成——严格执行下面的配方，不要试图画立体透视图。

## 六色色板

| 角色 | 色值 | 用法与用量 |
|---|---|---|
| 深底 | `#3E3A32` 暖炭 | 封底或个别章节页；主画布永远暖米 |
| 主色 | `#B2AC88` 鼠尾草绿 | 主形体、图表第一系列、当前阶段强调 |
| 辅色 | `#DBADAD` 暖粉 | 次级形体、图表第二系列、温柔点缀 |
| 强调 | `#D9975E` 杏橙 | 关键数字、唯一焦点形体，全篇 ≤3 处 |
| 浅底 | `#FDF5E6` 暖米 | 全篇背景 |
| 正文 | `#333333` | 正文；弱化 `#6B6B6B`，分隔线 `#E7DAC8`，面板 `#FFF9EF`，影子 `#C8BBA8` |

## 字体与字号

- 全篇无衬线圆润感：`Microsoft YaHei, PingFang SC, Arial`（不写装饰字体）。
- 字号带：页标题 32~38pt bold｜副标题 18~22pt｜正文 13~15pt｜标签 13pt｜KPI 大数字 64~80pt。封面主标题 52~64pt。标题左对齐或居中（本风格允许封面/章节居中）。

## 母题（每页至少出现一次）

**圆底徽章**：一枚 56~72px 圆形色块（主色或辅色，alpha 100）托一个 28~32px 白色 icon，圆配 shadow soft——这是全篇的「黏土件」，用于要点图标、章节序号托底、流程节点。全篇同尺寸（72px 一档），每页 1~3 枚，位置随版式但尺寸不变。反母题禁忌：直角色块、细线框、渐变都不许当母题。

## 黏土感配方（引擎近似三件套，逐条执行）

1. **圆角**：面板/形体一律 roundRect；面板圆角用工具默认，装饰形体用 ellipse/圆角大的 roundRect。
2. **分层**：一个「形体」= 2~3 层同形状叠放——底层主色，右下偏移 6~10px 一层同形状深一档色（alpha 60~80）当侧影，左上一层 alpha 25~40 的白或浅色当高光。最多三层，绝不画透视。
3. **柔和阴影**：形体与卡片统一 shadow soft（影子色感用 `#C8BBA8` 底色自然带出）；禁 medium/strong 大阴影。

形体只放三处：页面右上或左下的**角落件**（半出血：圆心可出画布 1/4）、内容区的**焦点件**（一页最多一个，直径 ≤220px）、流程页的**节点**。形体后面不许藏正文。

## 预设风格化（结构坐标按 layout-ppt-skill 对应预设，这里只定皮）

- **P1 封面**：暖米底；锚点用「P1b 大色块的柔化变体——一块 ≥1/3 画布的圆角色块（主色或辅色）+ 白字大标题」或「右上角大焦点件 + 左侧超大字」。角落件 1~2 个即可，不许满页飘形体。元素 ≤6。
- **P3 章节页**：米底 + 圆底徽章托章节序号 + 大字章节名；或一块圆角主色横带（y 居中，高 220~280px）内放白字。
- **P4 目录**：左栏「目录」+ 圆底徽章；条目编号放在 40px 小圆（主色 alpha 20）内，标题 16~18pt。
- **P5 引用页**：米底 + 20~26pt 引言居中，引号 icon 白色压主色圆底徽章；署名 13pt。
- **D 数据页**：KPI 大数字杏橙或鼠尾草绿；图表系列色 `#B2AC88 → #DBADAD → #D9975E`；数字格不用直角面板，用 `#FFF9EF` 圆角面板托底。
- **T 表格页**：T1 行线式（行线 `#E7DAC8` 0.5pt、表头无底色 bold）+ 首列前留白多一点；表格是本风格里唯一允许「直」的元素，别给它加圆角底板。
- **F 流程页**：节点就是圆底徽章（内放序号或 icon），连箭头用 `#C8BBA8` 圆头细线；当前节点主色实心、其余主色 alpha 25。
- **图片页（P6/P7/P9）**：图片放圆角框（视觉上给图片套一层 `#FFF9EF` 圆角底板，图片内缩 12px）。

## 图片处理

素材直链选明亮、干净、圆融感的产品/工作台/插画感图片；图片同样可配 shadow soft。禁暗调、金属感、高对比图。

## 禁忌

禁真 3D 透视、金属光泽、玻璃拟态；禁高饱和糖果色与霓虹；禁满页漂浮形体（形体总量每页 ≤4 件）；禁直角面板配本风格（面板必须圆角）；禁 emoji（表情交给 icon）；图标随圆底徽章出现，无徽章不成 icon。
