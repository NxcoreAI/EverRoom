# 极简奢牌（Minimalist Luxury · 奢）

一句话身份：一本奢侈品牌的品牌手册——暖米色纸面上，衬线大字优雅地站在大留白里，棕金色只出现在一条细线、一个小标签、一个关键数字上。安静、精准、贵气；密度是它的敌人。

## 六色色板

| 角色 | 色值 | 用法与用量 |
|---|---|---|
| 深底 | `#3A3A3A` 深灰 | 封底或个别章节页；主画布永远是米色 |
| 主色 | `#A68A64` 棕金 | 细线、小标签、图表第一系列、点睛结构，<10% 面积 |
| 辅色 | `#BFAE93` 浅棕 | 次级结构、图表第二系列、弱化面板 |
| 强调 | `#6B4E36` 深铜 | 关键数字、唯一高亮词，全篇 ≤3 处 |
| 浅底 | `#F5EFE6` 暖米 | 全篇背景 |
| 正文 | `#3A3A3A` | 正文；弱化文字 `#746F68`，细线 `#D8CCBD`，浅奶油面板 `#FBF7F1` |

## 字体与字号

- 标题衬线 `Georgia`（fallback Times New Roman，Microsoft YaHei）400~600 字重——衬线是奢感的来源，禁粗黑体大字。
- 正文无衬线 `Inter, Arial, Microsoft YaHei`。
- 字号带：页标题 32~40pt 衬线｜副标题 18~20pt｜正文 13~15pt｜eyebrow 13pt 棕金（可大写、字间留空感）｜KPI 大数字 56~72pt 深铜。封面主标题 54~68pt 衬线。中英混排时英文衬线、数字衬线。

## 母题（每页至少出现一次）

**棕金细线 + 小型 eyebrow 标签**：一条 1px `#A68A64` 或 `#D8CCBD` 细线承担全部分隔（标题下 24px、栏与栏之间、图片上缘），配一行 13pt 棕金大写短标签（`MAISON · 2026`）。线永远 1px，位置语法全篇统一。反母题禁忌：粗色条、色块、阴影、圆角卡片都不许当母题。

## 预设风格化（结构坐标按 layout-ppt-skill 对应预设，这里只定皮）

- **P1 封面**：P1c 是本命——纯米底、衬线超大字（80~110pt，字即锚点）、eyebrow 与副题各一行、最多一条细线；禁图片满版、禁色块。元素 ≤5。
- **P3 章节页**：米底 + 居中或居左衬线大字章节名 + 章节编号用衬线 60pt 棕金（罗马数字 I/II/III 最贴）；上下各一条通宽细线。
- **P4 目录**：左栏「目录」衬线大字；条目间 1px 细线，编号衬线 20pt 棕金，标题 16~18pt 深灰；大量行距。
- **P5 引用页**：米底 + 衬线 24~30pt 引言（本风格引用页最好看），引号 icon 棕金；署名右对齐 13pt 弱化灰。
- **D 数据页**：KPI 大数字深铜衬线；图表第一系列 `#A68A64`、第二系列 `#BFAE93`、第三系列 `#D8CCBD`，去网格线（gridlines 不开）、dataLabels 直标；一页一图。
- **T 表格页**：T1 行线式变体——行线 `#D8CCBD` 0.5pt、表头无底色衬线 bold；合计行上方用 1px 棕金线代替加粗；密度低（行 ≥56px）。
- **F 流程页**：时间轴用 1px 细线 + 小圆点（8px 棕金实心/空心），当前阶段深铜；节点文字衬线。
- **图片页（P2/P6/P7/P9）**：图片直角满框或细线框（1px `#D8CCBD`），材质细节、建筑、空间、器物类高级摄影最贴；禁挤压多图拼贴。

## 图片处理

素材直链选低饱和、暖调、材质感强的图；每页最多一图；图片周围留白 ≥80px。饱和电商图、拼贴感会瞬间毁掉奢感。

## 禁忌

禁纯白背景（用 `#F5EFE6`）；禁重阴影；禁渐变（顶多不用）；禁圆角卡片与卡片阵（面板感用 `#FBF7F1` 直角色块）；禁高饱和色；禁 emoji；图标 ≤2 个/页、棕金或深灰单色线性。
