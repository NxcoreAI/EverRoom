# 现代插画编辑（Modern Illustration Editorial · 暖）

一句话身份：一流 SaaS 品牌站的插画系统——浅暖底上，雾蓝与灰橙两色的扁平形状拼出人物、流程与概念插画，文字栏冷静克制地排在另一侧。聪明、现代、轻微艺术感；不是卡通绘本。引擎没有矢量绘图能力，本风格的「插画」由**形状构图 + 素材图片**两条腿实现——每个插画区先想清楚用哪条腿。

## 六色色板

| 角色 | 色值 | 用法与用量 |
|---|---|---|
| 深底 | `#2F2F2F` 炭灰 | 封底或个别章节页；主画布永远浅暖 |
| 主色 | `#A7C7E7` 雾蓝 | 插画主形体、图表第一系列、大色块 |
| 辅色 | `#E8A87C` 灰橙 | 插画次形体、图表第二系列、暖点缀 |
| 强调 | `#5B8FB9` 深雾蓝 | 关键数字与文字级强调（雾蓝太浅不能当文字色），全篇 ≤3 处 |
| 浅底 | `#F7F3EE` 浅暖 | 全篇背景（内容页也可用 `#FFFFFF` 二选一并全篇统一） |
| 正文 | `#2F2F2F` | 正文；面板 `#EAF4FC`（蓝）与 `#FCE8DA`（橙）只用于插画层次，分隔线 `#DED8D1` |

## 字体与字号

- 全篇无衬线：`Inter, Arial, Microsoft YaHei`，标题 700 字重。
- 字号带：页标题 32~40pt bold｜副标题 18~22pt｜正文 13~15pt｜标签 13pt｜KPI 大数字 64~80pt（深雾蓝或炭灰）。封面主标题 54~68pt。标题左对齐，禁满页居中。

## 母题（每页至少出现一次）

**双色插画块**：每页一个用雾蓝/灰橙/浅面板三档色拼的形状构图（人物=圆头+圆角长方身体、流程=圆角节点+弧形连线用 line 近似、概念=两三个叠加圆与圆角块），或一张灰橙调素材图。构图元素 ≤6 件、只用画板三色（+白），全篇形体语言一致（全圆角，无直角尖角）。反母题禁忌：细线框、直角色块、阴影阵列都不许当母题。

## 插画构图配方（引擎近似，逐条执行）

- 主体用 ellipse（头/球）+ roundRect（身体/卡片/底座）叠 2~4 层；层次靠浅面板色（`#EAF4FC`/`#FCE8DA`）垫底、主色压面。
- 渐变只许在插画形体内部（主色→浅面板同族），全页 ≤2 个；阴影只给插画主体与图片，shadow soft。
- 插画区占内容区 40~60%，永远与文字栏不对称并排（P7 双栏），不居中独占。
- 禁拼超过 6 件的复杂场景；画不像的概念改用一张素材图或一个 chart，不硬凑。

## 预设风格化（结构坐标按 layout-ppt-skill 对应预设，这里只定皮）

- **P1 封面**：浅暖底；锚点用「P1b 大色块柔化变体——≥1/3 画布雾蓝圆角色块 + 白字标题」或「右半一幅插画构图 + 左侧超大字」。插画主体 ≤4 件。元素 ≤6。
- **P3 章节页**：浅暖底 + 大字章节名 + 一幅小插画块（≤3 件形体）或章节序号压在雾蓝圆角块上（白字）。
- **P4 目录**：左栏「目录」+ 小插画块；条目编号放 40px 圆（雾蓝 alpha 30）内深雾蓝字。
- **P5 引用页**：浅暖底 + 24~28pt 引言，引号 icon 深雾蓝；署名 13pt 灰。
- **D 数据页**：图表第一系列雾蓝太浅时用深雾蓝，第二系列灰橙、第三系列 `#DED8D1`；KPI 大数字深雾蓝；数字格用白或 `#EAF4FC` 圆角面板。
- **T 表格页**：T1 行线式（行线 `#DED8D1` 0.5pt、表头无底色 bold；或表头 `#EAF4FC` 浅蓝底炭字）。
- **F 流程页**：节点用圆角块（雾蓝系，当前节点灰橙实心），连线灰橙细弧线（line 近似）；节点内白字或炭字。
- **图片页（P6/P7/P9）**：图片圆角框（内缩 12px 套 `#FFFFFF` 圆角底板）+ shadow soft；灰橙调或柔和色调的图最贴。

## 图片处理

素材直链选柔和、明亮、插画感或干净产品图；每页最多一图。暗调、高饱和、写实粗糙照片会破坏气质。

## 禁忌

禁卡通吉祥物、贴纸感、3D 写实；禁重阴影与光泽；禁霓虹与高饱和；禁仪表盘式密集排版；禁直角尖角形体（插画块全圆角）；禁 emoji；图标 ≤3 个/页、深雾蓝或炭灰单色。
