# 日式生活杂志（Japanese Lifestyle Editorial · 锐）

一句话身份：一本高级生活杂志的内页——纯白底上炭灰字排得像栅格一样准，焦橙只作为记号出现，图片直接顶到画布边缘制造张力。比和纸柔光更快、更锐、更图形化；不适合强工程汇报（那用 futuristic-tech-editorial）。

## 六色色板

| 角色 | 色值 | 用法与用量 |
|---|---|---|
| 深底 | `#2B2B2B` 炭黑 | 几乎不用：封底或个别章节页；主画布永远是纯白 |
| 主色 | `#CC5500` 焦橙 | 记号级使用：编号、短横线、关键数字、当前页签，<10% 面积 |
| 辅色 | `#8A8580` 暖灰 | 次级结构、图表第二系列、弱化标签 |
| 强调 | `#71362B` 深陶 | 图表第三系列、署名与图注级文字的强调色 |
| 浅底 | `#FFFFFF` | 全篇背景，纯白不将就 |
| 正文 | `#333333` | 标题与正文；弱化文字 `#8A8580`，细线 `#D9D9D6`，浅灰面板 `#F4F2EF` |

「大部分白 + 炭灰 + 一点焦橙」是本风格的呼吸方式；焦橙到处都是就毁了它。

## 字体与字号

- 全篇无衬线：标题 `Arial, Microsoft YaHei` bold；小标签/编号用 `Consolas` monospace 大写（如 `ISSUE 02 / FRAMEWORK`）——monospace 小标签是本风格的签名细节。
- 字号带：页标题 32~40pt bold｜副标题 18~22pt｜正文 13~15pt｜monospace 标签 13pt｜KPI 大数字 64~80pt。封面主标题 56~68pt。标题一律左对齐。

## 母题（每页至少出现一次）

**焦橙记号 + monospace 标签**：每页固定出现一对——左上或标题上方一枚焦橙短记号（12×6px 焦橙 rect 或 8px 焦橙圆点）+ 一行 13pt monospace 大写栏目标签（`TREND / 01`）。位置全篇统一（如固定 x=60, y=44），像杂志的页眉系统。反母题禁忌：色条、角标、渐变都不许当母题。

## 预设风格化（结构坐标按 layout-ppt-skill 对应预设，这里只定皮）

- **P1 封面**：纯白底；锚点用「≥80pt 超大字」或「P1b 大色块的焦橙变体——≥1/3 画布焦橙色块（右侧竖带或下半横带）内放白字大标题」。压边图封面：一张图直接顶满右上或右半（ bleeding 到画布边缘），左侧白区放标题组；图上文字必须垫实色白块或半透明白（alpha 85+）。元素 ≤6。
- **P3 章节页**：纯白底 + 焦橙大号章节编号（01/02，monospace 60~80pt 焦橙）+ 炭灰大字章节名；不用深色满版。
- **P4 目录**：左栏 monospace「CONTENTS」+ 焦橙短记号；条目两位数编号焦橙 monospace 20pt，标题炭灰 16~18pt，条目间细灰线。
- **P5 引用页**：纯白底 + 炭灰 24~28pt 大字引言（不用衬线），引号 icon 焦橙；署名 13pt 深陶。
- **D 数据页**：KPI 大数字焦橙（全页只一个焦橙数字，其余炭灰，焦点立现）；图表系列色 `#CC5500 → #71362B → #8A8580`，单系列一律焦橙；轴线用 `#D9D9D6` 细线。
- **T 表格页**：T2 深表头变体——表头炭黑底白字，我方列表头焦橙底；行线 `#D9D9D6` 0.5pt，正文白底。
- **F 流程页**：节点等分、细灰线连接，当前阶段焦橙实心；每阶段编号用 monospace。
- **P6/P7/P9 图片页（本风格的主场）**：压边构图——图顶满右半 (640,0,640,720) 或顶到右/上/下任一边缘；文字锁对侧栅格；图与文字之间一条焦橙细线（1px）从文字区伸向图片做视觉连接；不用圆角不用阴影。

## 图片处理

素材直链选锐利、亮度高、留白多的产品/空间/人物图；裁剪必须故意（顶边、顶角），不许不小心裁掉主体。每篇压边大图 ≤3 页。

## 禁忌

禁纸纹底、柔光、圆角有机形状（那是和纸/黏土风格的事）；禁重阴影；禁居中排正文；禁三张以上等宽同款卡片一排；禁 emoji；图标 ≤2 个/页且只为导航记号。
