# 流程与结构页布局（二级）

流程页原则：**方向感唯一**——整页只往一个方向流动（横或竖），节点等距、连线等长；阶段不超过 6 个，超过就拆页。

## F1 圆点箭头流程页

适用：战略路径、方法论、阶段性打法。

- 两组「圆→箭头→圆」横排（每组占半页宽）：椭圆/圆形节点 120~160px 内放节点名，节点间用 lineArrow 连接。
- 上方或节点组之间放一条全宽横幅色条 (60,140,1160,64) 写阶段主张（同 F2 横幅）。
- 节点下方各配 13pt 两行说明；节点+说明成组，组间距 ≥60px。
- 箭头统一长度、统一颜色（弱化灰或主色），不逐段变色。

## F2 横幅+卡片阵页

适用：资金使用、特性总览、多要点并列。

- 标题区下一条深色横幅 (60,140,1160,72)：左端白色 18~20pt 主张句，右端可放一个大数字。
- 横幅下 3~6 张等宽卡片：每卡「序号或 icon + 16pt bold 标题 + 13pt 两行正文」。
- 3 卡横排每张 373；4 卡每张 275；6 卡用 3×2 网格（373×260）。
- 卡高按内容区均分（纵排 (540−(n−1)×20)÷n）；卡片间距全篇统一 20。

## F3 时间轴页（水平）

适用：里程碑、发展计划。

- 一条水平主线（y=400 附近，60~1220，2~3px 高 rect 或 line，弱化色）。
- 4~6 个 14px 圆点等距分布在线上；已完成节点主色、未来节点描边空心。
- 奇偶交替：点上方放「时间 16pt bold + 事件 13pt 两行」，点下方错开放下一组；上下文字块与线间距 ≥24px。
- 事件多的场合用竖向变体：主线 x=200 竖贯 140~680，事件全部右侧纵排，行距均分。

## F4 阶段路线条页

适用：产品路线图、融资阶段、批次计划——比时间轴更强调「当前在哪」。

- 内容区横向 3~4 段全宽横条：每段一条 (60, y, 1160, 高 90~110) 的浅底圆角条，段与段间距 20，段高按 (540−(n−1)×20)÷n。
- 每条内：左端时间/阶段名（18pt bold，占 260）+ 右侧该阶段 2~3 个交付要点（13pt，横排间隔 40）。
- 已完成段：主色浅档底+左端打勾 icon；当前段：主色底白字（唯一强调）；未来段：灰浅底。
- 时间流向自上而下；不加箭头装饰。

## F5 分层架构页

适用：技术架构、组织架构、体系总览。

- 内容区 3~5 层全宽横条：每层一条浅底 roundRect (60, y, 1160, (540−(n−1)×16)÷n)，层间距 16。
- 每层左端 120px 色带区放层名（14pt bold，深色或白字），右侧放该层模块小卡（等分排布，模块名 13pt）。
- 层间用 2~3 条短竖线（或省略）表达依赖方向；底层是数据/基础设施，顶层是用户/入口。
- 模块小卡不加边框，用底色差区分；每层模块 ≤6 个。

## F6 竖向里程碑页

适用：单线程历程、成长轨迹、施工节点。

- 左侧竖线 (x=140, y=140~680, 2~3px) + 4~6 个 14px 圆点等距。
- 每点右侧一段「时间 16pt bold + 事件 13pt 一两行」，段高 = 540÷n，内容垂直居中于段。
- 右侧 1/3 可放一张配图或一张结论卡 (860,140,360,520)。
- 奇偶不交替（竖版交替会乱），全部右侧对齐。

## 通用工艺

- 节点/圆点尺寸全页统一；连线粗细统一（1~2px）；强调只给一个元素（当前阶段/高亮节点）。
- 阶段名 ≤6 字；要点每条 ≤20 字，放不下就精简内容，不缩字号。
- 流程方向与页序叙事一致（左→右、上→下）；时间永远向右或向下。
