# 表格页布局（二级）

表格页的第一原则：**表格是页面的主角，不是填在缝隙里的插件**——表格撑满内容区（60,140,1160,~520），结论写进页标题（行动标题），不占表格行，不配说明小字。

## 表格工艺总则（所有预设通用）

- 字号：表头 13~14 bold，正文 13~14；超过 8 行才允许降到 12。
- 行高：正文行 ≥52px（行多时 ≥44px）；表头行高略高于正文（rowHeights 首项 1.1~1.2）。
- 折行预算：引擎构建时按真实排版实测表格高度，单元格文字折行会把行撑高，实测总高超声明框就整页拒绝（报错带实测数字）。框高按最坏列的「行数 × 行高」累加预算，单元格文字争取一行放下、最多两行；数据真放不下就拆两页，不缩字号硬塞。
- 列宽按内容权重给 colWidths：标签列 0.8~1.2、数字列 1、星级/勾选列 0.6~0.8、长文本列 1.5~2。短标签列给宽了是表格最常见的不均衡。
- 对齐：文本左对齐、**数字右对齐**（align:"right"，千分位，单位写在列头如「收入（万元）」不逐格重复）、勾选/星级居中、表头对齐跟随该列内容。
- 我方列高亮：fill 用主色浅档或整列 bold，其他列保持素净——不逐列配彩虹色。
- 表格上下不加横幅、不放图注式说明；需要强调的数字加 bold 或主色即可。

## T1 行线式（默认推荐，咨询风）

适用：参数对照、指标表、通用数据表。最克制耐看的表格形态。

- 结构：页标题（行动标题）→ 表格 (60,140,1160,520) 撑满。
- 写法：`borderColor` 用浅灰（取风格色板的分隔线色）、`horizontalBordersOnly: true`、`borderWidthPt: 0.5`；表头**无底色**、bold、深字色；正文白底。
- 表头与正文的分隔由第一条行线自然承担；全文无竖线，视线横向扫读。
- 示例要点：
  `{"type":"table","x":60,"y":140,"w":1160,"h":520,"fontSize":14,"borderColor":"<风格分隔线色>","horizontalBordersOnly":true,"borderWidthPt":0.5,"colWidths":[1,1,1,1],"rowHeights":[1.15,1,1,1],"rows":[[表头 bold],…]}`
- 我方列提亮：该列表头加 fill 主色+白字，正文该列 bold；仅此一列。

## T2 深表头行线式

适用：竞品对比、多列对照——表头信息需要更强分界时。

- 写法：在 T1 基础上表头整行 fill 深主色 + 白字 bold + 居中；正文仍只用行线。
- 我方列表头用辅色或更深一档，形成「列锚」；正文我方列 bold。
- 行数 ≤6 时最稳；行多改用 T1 或 T3 减压。

## T3 斑马清单式

适用：多行清单、排期表、价格表（行 ≥7）——行线太密时改用隔行底色导航。

- 写法：不传 borderColor（无边框）+ `zebra:"<风格最浅底色>"`；表头 bold 深字无底色，表头下可叠一条 2px 主色 rect（无文字形状，不与文字冲突）做分界。
- 行高均匀、字号 13；首列 bold 当行标签。
- 竖线永远不画；确需分列用 colWidths 拉开列距即可。

## T4 卡片行式（弃用表格元素）

适用：≤5 条、每条文字较多（两行以上）的清单——成员介绍、功能列表、条款要点。硬表格放长文本会很挤，改用行卡。

- 结构：n 张全宽 roundRect 行卡 (60, 140, 1160, (540−(n−1)×20)÷n)，浅底、shadow soft。
- 卡内：左侧 24~28px icon（可选）+ 16pt bold 标题 + 13pt 两行正文；文字与卡边 ≥16px，标题正文间距 8。
- 卡与卡间距 20；不做逐卡变色。

## T5 矩阵评分式

适用：评测矩阵、需求打分、优劣势对比。

- 写法：table + 单元格放 ✓/✗ 或 ★★★☆☆（居中）；强度用底色热力表达——优=主色浅档、中=灰浅档、劣=更浅灰或留白，全表只用这一套深浅。
- 星级列 colWidths 0.6~0.8；行标签列 bold。
- 结论列（若有）放最右，bold + 主色字，不加底色。

## T6 财务表

适用：财务预测、预算、报价——数字密度最高的表。

- 写法：T1 行线式打底 + 工艺强化：所有数字列 align:"right"、千分位、单位进列头；首列（项目名）左对齐 bold。
- 合计行：整行 span 合并或首列写「合计」+ bold + 主色字，rowHeights 给该行 1.2，其上方那条行线就是天然分隔（无需额外强调）。
- 列数 ≤5 最佳；年份/科目多时拆两页，不缩字号硬塞。

## T7 双栏对照式（VS，不用表格元素）

适用：二选一方案对比、前后对比、迁移前后。

- 结构：左右两张卡 (60,140,560,500) 与 (660,140,560,500)，中缝 x=620~700 放一个 64×64 圆形徽标写「VS」（主色底白字）。
- 每卡：顶部 20pt bold 方案名 → 3~5 条要点（14pt，每条一行，行距 36）。
- 胜出方卡片 fill 主色浅档+边框主色，另一方素净；结论写进页标题（如「方案 B 以一半成本覆盖相同场景」）。

## 选型速查

行少信息密 → T1/T2；行多 → T3；文字长 → T4；打分 → T5；数字重 → T6；二选一 → T7。
