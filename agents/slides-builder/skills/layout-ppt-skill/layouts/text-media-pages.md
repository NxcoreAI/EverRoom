# 文字与图文页布局（二级）

## P1 封面（a/b/c 三选一）

封面必须有一个视觉锚点，四选一：**满版深色底、≥1/3 画布面积的主色块、≥80pt 超大字、主视觉大图**。浅色小卡片、细线列表、小图标、短横线都不算锚点。封面只放身份信息（主标题、副标题、日期/机构行），不放参数规格、特性清单、KPI——那是内容页的事；封面元素总数 ≤6。

### P1a 深色大字封面（默认选它）

适用：绝大多数封面，商务/科技/汇报皆宜。

- 全页深色背景（设计系统深主色或近黑），背景即锚点。
- 左对齐文字组整体垂直居中：eyebrow 一行 13pt（如 PROJECT PROPOSAL · 2026，弱化色）、主标题 54~72pt bold 白字（中英混排英文可更大）、副标题 18~20pt 弱化白，行距拉开（标题与副标题 ≥32px）。
- 可选背景层次：右下角一个超大低透明度（alpha 12~18）同色系字或数字（150pt 级），只此一个；重叠校验按**整个文本框**算不按字形——背景大字的框不得与任何其他文本框相交，其他文本框宽度按实际文字收窄给它让位。
- 无卡片、无细线、无规格列表；日期/机构并入 eyebrow 或副标题。

### P1b 大色块封面

适用：亮色系风格（焦橙/电蓝/黏土）或要强冲击的白底封面。

- 白/浅底 + 一块 ≥1/3 画布面积的主色块：整右侧竖带（x=640~1280 满高）或下半横带（y=400~720 满宽），主色纯色或设计系统渐变；色块即锚点。
- 主标题放色块内，48~64pt bold 白字，副标题跟随；色块外留白区放 eyebrow 与日期（13pt）。文字与色块边缘 ≥40px。
- 除色块外无装饰。

### P1c 超大字白底封面

适用：极简奢牌/编辑风；仅当所选风格本身是白底大留白系才用。

- 白底，主标题 80~110pt bold、占画布宽 70% 以上（左对齐或居中，垂直居中）——字本身就是锚点。
- 其余全部克制：eyebrow 13pt 与副标题 18pt 各一行，间距拉开；最多一个 icon。
- 无卡片、无色条、无细线；留白就是设计。

## P2 大图压字愿景页

适用：愿景/宣言/情绪页。

- 全幅图片一张 (0,0,1280,720)，叠半透明遮罩矩形（`#RRGGBBAA`，alpha 视图片明暗 40~70，深色图用主色系遮罩）。
- 居中两行白字：主张 y=300 起 36~48pt bold，副句其下 16~20pt；文字可加 shadow。
- 不加图注；每篇大图页（P2/P9）合计 ≤3 张。

## P3 深色章节页

适用：篇章分隔，叙事换挡。

- 全页深色背景（深主色或近黑藏青），无图。
- 居中或左对齐一行大字（40~56pt 白字）+ 一行 16~18pt 弱化白副句。
- 可加一个超大章节序号（120pt 级、低透明度同色系）做背景层次。
- 每篇 ≤2 页。

## P4 目录页

适用：开篇后的议程页。

- 结构：左侧栏 (60,140,320) 放「目录/Agenda」大字（28~36pt）+ 可选一句主线副题；右侧条目区 (440,140,780)。
- 条目 4~6 条：每条「两位数编号（01 02…，20pt bold 主色）+ 条目标题（16~18pt）」一行，行距均分 540（行高 = 540÷n，文字垂直居中于行内）；编号与标题左对齐成列。
- 可选右侧细线分隔条目；不加页码小字。

## P5 大引用页

适用：金句、用户证言、创始人宣言。

- 居中或左对齐大引言（24~32pt，占内容区宽 80%），y=220 起。
- 引言左上方放一个大引号 icon（48px，主色）做锚点。
- 署名（14pt，人名 bold + 头衔灰字）右对齐放引言下 40px。
- 背景纯色；除引号 icon 外无装饰。

## P6 半图半卡痛点页

适用：痛点、场景列举。

- 左半大图 (60,140,600,520)：不加图注，图即内容。
- 右半三张卡片 (700,140,520,160，间距 20 纵排)：浅底 roundRect + shadow soft，卡内「icon 28px + 16pt bold 小标题 + 13pt 两行正文」，文字与卡边 ≥16px。
- 卡片多于 3 张改两列小卡（255×220×2 列）。

## P7 双栏图文页

适用：产品介绍、特性说明、图文对照。

- 左右两栏（各 570）：一栏图 (60,140,570,520)，一栏文字 (670,140,570,520)——文字栏放 20pt 小标题 + 13~14pt 正文 + 要点列表。
- 图在左或在右按叙事定，相邻页交替方向形成节奏。
- 文字栏内容垂直居中，不顶头挤在上部。

## P8 履历/竖轴页

适用：团队介绍、单主题多段履历、发展历程。

- 左列窄结构 (x=60，宽 260)：竖向节点轴——3~4 个 12px 圆点等距排布 (y=200~600)，每点右侧 24px 一段「小标题 16pt bold + 2~3 行正文 13pt」，段高按行数算足。
- 右列 (380~1220)：一段大引言或核心成就（20~24pt）+ 支撑要点。
- 变体：左列换窄色带竖排标签（40px 色块内竖排 14pt 白字）。

## P9 封底联系页

适用：结尾页。

- 左列 (60,120,480)：logo 锚点 + 口号（20pt）+ 联系方式列表（14pt，邮箱/电话/地址各一行，行距 36px）。
- 右侧大图 (600,0,680,720) 产品图/氛围图压满右缘；不加版权/致谢小字。
