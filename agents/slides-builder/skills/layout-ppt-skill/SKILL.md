# 布局技能（一级总纲）

分工：风格技能定色板与字级，本技能定结构与几何。用法：create 第 3 步读本文件，按叙事定页序节奏、给每页指定预设；**填每一类页之前**按「布局选择器」读对应的二级布局文件（填表格页前必读 table-pages.md，依此类推），预设里的坐标骨架直接套用。

布局策略来源：咨询报告式（行动标题+行线表格+一页一论点）、杂志编辑式（不对称分栏+大留白）、主题演讲式（一页一句话）、瑞士网格（严格等分与对齐）。所有预设只定结构与坐标，颜色一律取所选风格的设计系统。

## 网格系统（一切布局的底）

- 画布 1280×720；左右边距 60，上边距 40，下边距 40。
- 页标题区 y=40、h=60：标题 32~40pt 左对齐；标题即结论（行动标题），不写「XX 概览」这类中性标题。
- 内容区 y=140 起、y=680 止 → 可用 **1160×540**。
- 全篇所有间距只从 4 的倍数里取（8/12/16/20/24/32/40/48）；同方向的间距必须相等。

## 等分公式与速查表

n 等分宽 = (1160 − (n−1)×间距) ÷ n；纵向把 1160 换成 540。

- 横向（间距 20）：2 列 570 ｜ 3 列 373 ｜ 4 列 275 ｜ 5 列 216 ｜ 6 列 176
- 纵向（间距 20）：2 行 260 ｜ 3 行 167 ｜ 4 行 120
- 除不尽的余数给最后一格（373+373+374=1160）；第 k 列左缘 x = 60 + (k−1)×(宽+20)。

## 均匀性法则（反「布局不均匀」的硬规则）

1. **内容必须碰到内容区底边 680**——主元素（表格/图表/卡阵）按内容区高度撑满，绝不挤在上半部留大片空白；这是最常见的失衡来源。
2. **同排卡片等宽等高**；多排时列缝上下对齐（左缘永远落在同一组竖线上）。
3. **一页一个视觉焦点**：主元素占内容区 ≥50% 面积或最强字重，其余元素从属。
4. **同类信息同字号同对齐**；数字列右对齐成列（千分位/单位统一）。
5. 卡片内文字与卡片边 ≥16px；卡片标题与正文间距 8~12px。
6. 填完每页过一遍自检：间距一致？底边碰到 680？同排等高？焦点唯一？表格列宽按内容分？数字右对齐？

## 页序节奏（BP/汇报类叙事）

封面(P1a 深色大字 / P1b 大色块 / P1c 超大字，三选一、默认 P1a；锚点硬规则见 text-media-pages.md) → 目录(P4) → 团队(P8) → 愿景(P2) → 市场/痛点(D1/P6) → 产品与定位(D4/P7) → 竞品与技术(T2/T5) → 战略与时间(F3/F4) → 融资与财务(D3/T6) → 封底(P9)，全篇 18~24 页。相邻页不同预设；深色章节页(P3)与全宽图表页(D3)各 ≤2；大图页(P2/P9)合计 ≤3（受每页图片上限约束）。
