# 未来科技编辑（Futuristic Tech Editorial · 数据锐）

一句话身份：一本高端科技杂志——白得发亮的画布上，石墨灰的粗标题压阵，电蓝只作为信号灯亮在真正重要的那个数字上，细线网格撑起整个版面。精准、克制、商务可信；全场无阴影无渐变，纯平到底。

## 六色色板

| 角色 | 色值 | 用法与用量 |
|---|---|---|
| 深底 | `#16202E` 深藏青 | 几乎不用：封底或个别章节页；主画布永远纯白 |
| 主色 | `#2B2B2B` 石墨灰 | 标题、粗结构、表头，版面的骨 |
| 辅色 | `#6B7A90` 蓝灰 | 次级文字、图表第二系列、弱化标签 |
| 强调 | `#2F6BFF` 电蓝 | 信号不是装饰：关键数字、当前节点、图表第一系列，<10% 面积 |
| 浅底 | `#FFFFFF` | 全篇背景 |
| 正文 | `#2B2B2B` | 正文；细线与网格 `#E6EAF2`，浅面板 `#F7F9FC` |

电蓝一页最多一处高亮；到处是蓝 = 没有信号。

## 字体与字号

- 全篇无衬线：`Inter, Arial, Microsoft YaHei`，标题 700~800 字重。
- 字号带：页标题 32~40pt bold｜副标题 18~22pt｜正文 13~15pt｜eyebrow/坐标标签 13pt 蓝灰｜KPI 大数字 64~80pt。封面主标题 56~72pt。标题一律左对齐。

## 母题（每页至少出现一次）

**坐标记号系统**：细线网格片段 + 方括号/刻度记号——如内容区角落一组 1px `#E6EAF2` 十字刻度线、标题左侧一组 `13pt monospace 感` 蓝灰小标签（`01 / SYSTEM`）、数据模块四角 8px 直角短线（rect 拼 L 形）。位置语法全篇统一。这是「仪器面板」的意象：线是刻度不是分隔条。反母题禁忌：色条、圆角卡片、阴影都不许当母题。

## 预设风格化（结构坐标按 layout-ppt-skill 对应预设，这里只定皮）

- **P1 封面**：纯白底；锚点用「≥80pt 超大石墨字 + 一个电蓝元素」——大字标题、一个电蓝关键数字或一条电蓝 4px 短横线；eyebrow 用蓝灰 `PRODUCT LAUNCH / v2.0`；四角坐标刻度线收边。元素 ≤6。
- **P3 章节页**：纯白底 + 电蓝超大章节序号（monospace 100~120pt）+ 石墨大字章节名 + 一条 1px `#E6EAF2` 通宽细线。
- **P4 目录**：左栏「AGENDA」蓝灰 monospace；条目两位数编号电蓝 monospace 20pt，标题石墨 16~18pt，右侧对齐一条细灰线。
- **P5 引用页**：白底 + 石墨 24~28pt 引言（不居中、左对齐），引号 icon 电蓝；署名 13pt 蓝灰。
- **D 数据页（本风格的主场）**：图表第一系列电蓝、第二系列 `#6B7A90`、第三系列 `#B9C4D4`，轴线 `#E6EAF2` 1px，dataLabels 只标关键点；KPI 大数字电蓝、标签蓝灰；数字一律右对齐成列、千分位。
- **T 表格页**：T1 行线式——行线 `#E6EAF2` 0.5pt、表头无底色石墨 bold、数字列右对齐；我方列用电蓝表头字或该列 bold，不整列铺色。
- **F 流程页**：节点方形直角（rect，白底 1px `#2B2B2B` 描边），当前节点电蓝实心；连线 1px 蓝灰，长度统一；每阶段编号 monospace。
- **图片页（P2/P6/P7/P9）**：少用图；用则直角满框、不对称裁切（顶边或贴一侧），产品 UI/架构图/硬件细节最贴；图上不放字。

## 图片处理

本风格数据模块优先于图片——能画 chart 的不放假照片。素材直链选冷调、锐利的技术感图片；暖调生活图会破坏气质。

## 禁忌

禁阴影（全篇 shadow 一律不写）；禁渐变；禁圆角（roundRect 圆角感一律用直角 rect 替代；卡片感用 `#F7F9FC` 浅面板或细线框表达）；禁紫蓝渐变发光；禁 emoji；图标 ≤3 个/页、1px 线性图标、石墨或电蓝单色。
