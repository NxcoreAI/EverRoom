# 和纸柔光（Japanese Washi · 静）

一句话身份：一张安静的和纸桌面上，靛蓝墨色只落在该落的地方——克制、温润、专业而不冷淡。适合正式汇报、人文品牌、年度总结；不适合需要强冲击的营销场。

## 六色色板（设计简报的底稿，全篇只用这六色角色 + 器物灰）

| 角色 | 色值 | 用法与用量 |
|---|---|---|
| 深底 | `#22303F` | 几乎不用：仅封底或全篇极个别深色页；封面保持纸色 |
| 主色 | `#2C3E50` 靛蓝 | 标题、细线、结构元素、图表第一系列，约 30% 视觉权重 |
| 辅色 | `#8995B7` 蓝灰 | 次级结构、图表第二系列、弱化标签 |
| 强调 | `#AA6F5F` 陶玫瑰 | 全篇 ≤3 处：唯一的关键数字或一个高亮词 |
| 浅底 | `#F5F5F5` 和纸 | 内容页背景（封面也用它，本风格不做满版深色封面） |
| 正文 | `#333333` | 正文；次级文字 `#6B6B6B`，分隔线 `#D8D6D0` |

器物灰（`#D8D6D0` 分隔线、`#6B6B6B` 次级文字）是纸面上的墨度衰减，不算新增色。禁纯黑 `#000000`；禁高饱和色；禁彩虹多色。

## 字体与字号

- 标题：衬线 `Georgia`（fallback Microsoft YaHei）——衬线是本风格的温度来源。
- 正文：`Microsoft YaHei, PingFang SC`。
- 字号带（全 deck 统一）：页标题 32~36pt 衬线 bold｜副标题 18~20pt｜正文 13~15pt｜eyebrow/标签 13pt 蓝灰｜KPI 大数字 64~80pt 靛蓝。封面主标题 54~64pt。

## 母题（每页至少出现一次）

**细靛蓝线 + 小靛蓝圆点**：一条 1px 靛蓝细线（高 1px 的 rect）做段落或栏目的分界，线端点落一枚 8~10px 靛蓝实心圆。全篇线的位置语法统一（如固定在标题下 24px），变奏只改长短。这是「墨线」的意象——不是装饰条，是从纸面书法来的结构线。反母题禁忌：色条、角标、卡片左缘竖条都不许当母题。

## 预设风格化（结构坐标按 layout-ppt-skill 对应预设，这里只定皮）

- **P1 封面**：默认 P1a 的纸色变体——`#F5F5F5` 满版纸底，锚点用「≥80pt 超大衬线字」或「左缘一条通高 2px 靛蓝竖线 + 超大字」；eyebrow 用 13pt 蓝灰 monospace 感短标签（`PROJECT PROPOSAL · 2026`）；右侧留白区可放一个超大低透明度（alpha 10~14）靛蓝字。元素 ≤6。
- **P3 章节页**：纸底 + 居左大字，靛蓝细线上下各一条（40px 与内容区间）；可用 120pt 级 alpha 08~12 靛蓝章节序号压右下。
- **P4 目录**：左栏「目 次」衬线大字 + 靛蓝细竖线；条目编号用靛蓝 20pt，条目间 1px 器物灰细线。
- **P5 引用页**：纸底 + 衬线 24~28pt 引言，引号 icon 靛蓝 48px；署名右对齐 13pt 蓝灰。
- **D 数据页**：KPI 大数字靛蓝，标签蓝灰 13pt；图表第一系列靛蓝、第二系列蓝灰、第三系列 `#B9BFD4`，dataLabels 能省则省；D1 数字格之间用细竖线分隔代替卡片。
- **T 表格页**：T1 行线式是本命——`#D8D6D0` 行线 0.5pt、表头无底色 bold 深字；我方列表头一个靛蓝底白字格即可，不整行深底。
- **F 流程页**：节点用纸色圆 + 1px 靛蓝描边（非实心大色块），箭头细、统一器物灰；当前阶段节点实心靛蓝。
- **图片页（P2/P6/P7/P9）**：图片放细描边框（1px `#D8D6D0`）或直角满框，不加圆角不加阴影；图注不放（小字纪律）。

## 图片处理

素材直链图片裁剪留白多、亮度高的；暖调工艺、建筑、纸材、器物类图最贴。图片永远不做满版压字大图（那会毁掉纸感），最多占半页。

## 禁忌

禁纯白 `#FFFFFF` 大面积背景（用 `#F5F5F5` 纸色）；禁满版深色封面；禁阴影叠卡片（卡片用细线框或浅一档底色，不用 shadow）；禁渐变；禁 emoji；图标 ≤3 个/页、靛蓝或炭色单色。
