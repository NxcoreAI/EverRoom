# 规划一层写作路线

步骤：

1. 读 `title`（与可选 `description`），明确这份新文档要写什么、用户的意图是什么。
2. 通读 `material`（关联 Room / 实体 / 事实 / 文档与引用），找出与新文档主题相关的已有知识，作为路线的扩展底子。
3. `initial`：想出写这份文档的 3-5 条根本走法（主线/立场/覆盖面级别的路线选择），彼此差异放到最大；`expand`：只在 `targetLabel` 之下想 2-3 条更具体的深化分岔，每条都落在父方向的内部、比父级更可执行。全图最多四层，`pathContext` 已有三段时这次产出的是末梢层，选项要具体到可直接落笔。
4. 每条路线给短语 `label`（≤40 字符）与一句话 `note`（≤60 字符，说清走向）。
5. 自检：数量符合层级（第二层 3-5、深化层 2-3）；深化层逐条与祖先链比对，同义换装也算重复；label 全是短语；相关素材被路线利用；无编造事实。
6. 调用 `subagent_submit_result` 提交 `{ kind: "route-options", options }`。
