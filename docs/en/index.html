EverRoom guide

Get started with EverRoom

Keep project sources, documents, and Agent sessions together in one Room.

Your first session

  1. Install and finish setup

    Configure a model, add your work context, and create your first Room.

  2. Connect one source

    Add a project folder under Sources and wait for the sync to finish.

  3. Open the Room

    Check its goal, attached sources, and overview.

  4. Complete a small task

    For example: “List this week's action items from this Room and cite each source.”

Platforms

macOS for Apple Silicon is the primary build. Mobile test builds are available through iOS TestFlight and Android.

Get started

Download and install for macOS

The desktop app supports Apple Silicon (M-series chips). Download it from GitHub Releases.

Install

  1. Download the installer

    Choose the latest prerelease and download the file containing arm64.dmg.

  2. Install the app

    Open the DMG and drag EverRoom to Applications.

  3. Open EverRoom

    Launch it from Applications and grant file, microphone, or system-audio access when needed.

Mobile test builds

Test the iOS build with TestFlight, or download the Android test build.

Get started

First launch

Finish setup once, then connect a source and start working.

1. Configure a model

Sign in for hosted configuration, or enter the base URL, model name, and key for a compatible model. Continue after the connection test passes.

2. Complete onboarding

  1. Add your work context

    Describe your role, current goal, and preferred Agent behavior. You can update this later under Settings → Memory setup.

  2. Create your first Room

    Choose Project or Topic, then use a clear name and goal, such as “Website redesign — finish pre-launch review.”

  3. Choose the scope

    Grant access only to the current project folder, not your entire home directory.

3. Check that EverRoom is ready

Continue when Gateway no longer shows a startup or connection error and Sources and Context Room open from the sidebar.

Change language

Open Settings and choose English or Simplified Chinese.

User guide

Connect your first source

Start with a small project folder and verify the sync.

Add a local folder

  1. Open the source menu

    Open Sources from the sidebar and select Connect source.

  2. Choose a type

    Select File recognition folder, choose the project directory, and allow access.

  3. Wait for the scan

    When the folder appears in the source list, wait for scanning to finish. Expand it to view recognized files.

Connect other sources

GitHubEnter the repository and branch. Private repositories also need a token.
ObsidianSelect a vault to mount it continuously as a project Room.
Online servicesChoose a connector, complete authorization in the browser, then return to EverRoom.

Confirm the connection

  • The source list shows no failure.
  • Expanding the source shows the expected files.
  • Opening a file shows its content, source, and version.
Your originals are not changedDisconnecting removes EverRoom's copies and indexes, not the local or cloud originals.

User guide

Create a Context Room

Use one Room for one clear project, topic, person, or long-term goal.

Create a Room

  1. Open Context Room and select “+” beside My Rooms.
  2. Choose a type, then enter the name, goal, and essential background.
  3. Select Create Room. If EverRoom finds a similar Room, check it before creating a duplicate.

Add working material

Open the Room and add relevant sources or import Markdown from the Resources area. Keep unrelated material in its original source.

Check the Room

  • The Overview goal matches the current work.
  • Material opens and links back to its original source.
  • People, projects, and timeline items are not incorrectly attached.

Run the first task

Open the Agent in this Room and give it a specific task and format. For example:

Read this Room and list confirmed decisions, open questions, and next actions. Cite every item.

User guide

Create a document and use the Agent

Documents live inside Rooms. Use Documents to find and reopen them.

Create a document

  1. Open the target Room and select New document in Resources.
  2. Use a title that states its purpose, such as “August 28 product review decisions.”
  3. Add the goal, known facts, or an outline for the Agent to continue.

Edit and review history

Edit the body directly. Use the document actions menu to review earlier versions when you need to check a change.

Ask the Agent to edit

State the goal, scope, and output. Ask for citations when sources are involved, and review proposed changes before accepting them.

Turn this document into concise meeting notes. Keep decisions, owners, and due dates. Do not add unsupported facts.

Export

Choose Markdown, PDF, or DOCX from the document actions. Open the exported file and check headings, tables, and images.

User guide

Review and manage memory

Memory carries context across sessions. It does not replace the original source.

Find a memory

  1. Open Memory and search for a person, project, or decision.
  2. Open the result under Atomic memory, Conversations, Documents, or Scenarios.
  3. Follow its source back to the original before using it for important work.

Keep memory accurate

Review long-term context under Profile. Use Filter rules to say what should be kept or ignored. Correct or delete stale information.

A source did not enter memory

Open Ingest records and check the filter verdict and processing status. Reinstate an item if it was blocked by mistake.

Service unavailable

Skip memory setup when the service is unavailable. Local documents and the basic workspace remain usable.

User guide

Record and transcribe audio

Capture microphone or Mac system audio, then review the transcript and summary.

Grant access once

Allow Microphone access for microphone capture. For computer audio, allow Screen & System Audio Recording under macOS Privacy & Security, then quit and reopen EverRoom.

Make a recording

  1. Open recording and choose Microphone or Computer audio.
  2. Select the language and start. Record for more than 10 seconds.
  3. Stop and wait for the status to change from Processing to Completed.

Check the result

Open the event under Reality perception, play the audio, correct names, numbers, and terms, then select Save transcript. The summary updates from the corrected text.

User guide

Review tasks and diary

Track Agent runs, manage recurring work, and review daily activity.

Review Agent tasks

Open Office to see running, completed, and failed tasks. Open a task for its activity and result. Read the error before retrying a failed run.

Create a scheduled task

  1. Open Schedules, create a task, and state exactly what it should do.
  2. Choose the run time and repeat interval.
  3. Run it manually once. Enable the schedule only after its Room, sources, and output are correct.

Review a day

Open Diary and choose a date. Select Generate diary if it is empty, then use View source to check the documents, recordings, or activities behind each entry.

Development

Run from source

Requires Node.js 22+ and pnpm 11.

Start the project

git clone https://github.com/NxcoreAI/EverRoom.git
cd EverRoom
corepack enable
pnpm install
pnpm dev

Configure the Agent runtime

Copy .env.example to .env. The default fake runtime makes no model calls. Set the NXCORE_AI_* values for a real Agent.

Commands

pnpm devStart the desktop app
pnpm typecheckType-check
pnpm testRun tests
pnpm buildBuild the project

Manage

Settings and data

Manage your account, model, language, permissions, and local data.

Account and model

Sign in for hosted configuration, or configure a compatible model endpoint manually.

Local data

The default macOS data directory is ~/Library/Application Support/NxCore/.

Clear data

Clear all user data removes EverRoom's local databases, memory, recordings, and settings. It does not delete original folders or cloud data.

Manage

Troubleshooting

Check the build, permissions, and network first.

The app will not open

Confirm that the installer came from official Releases and its name contains arm64.dmg. Check macOS Privacy & Security for the block reason.

Gateway not ready

Quit EverRoom completely and relaunch. In development, inspect the terminal and ~/Library/Application Support/NxCore/logs/.

Model connection failed

Check the base URL, model name, API type, and key.

A file is missing

Check folder permission, file format, and source status.

No audio was recorded

Check microphone or system-audio permission and restart the app after changing it.
