# Excel Agent 主流程 20 条测试（含真实结构改动）

> v1 · 2026-10-31｜用于快速验收「agent 能不能真的把 Excel 改对」，20 条里 **12 条是行/列/工作表级别的真实结构改动**。
> 用例 ID `T-01…T-20`，每条的 `对应 XL-*` 指向 `docs/xlsx-agent-test-cases-expected.zh-CN.md` 的完整用例（含边界细节）。
> 数据：`test/fixtures/xlsx-agent/财务报表_2026年10月.xlsx`（主 fixture）、`销售明细_1万行.xlsx`（性能加测）。

## 怎么跑

1. **每条独立**：上一条跑完把文件**回退到基线 v0**（除 T-17→T-18 是链式的：先建图再改图）。
2. 每条只需两步：粘提示词 → 按「预期改动」核对 → 记「通过/不通过」。
3. 约 60–90 分钟可跑完一轮；建议每轮都跑全 20 条（这 20 条覆盖了改坏文件最常见的 20 种方式）。
4. 基线数值（核对用）：合计 应发 **193000**、社保 **33187.5**、个税 **10883.75**、实发 **148728.75**；技术部 4 人 / 实发 **72867.5**；个税最高 刘洋 **3420**。

## A 块：行与列的结构改动（最容易改坏文件的一类）

### T-01 · 插入行 `对应 XL-S-01`

**提示词**
```
在「薪酬明细」第 10 行前插入一行空行，插完检查一下最下面的合计行还对不对。
```

**预期改动**
- 原第 10 行（杨帆）及以下整体下移一行；第 10 行变为空行
- 合计行移到第 16 行，求和范围从 `E5:E14` 扩为 `E5:E15`
- 合计值**不变**：应发 193000、实发 148728.75

**通过标准**：`insert_rows` 单独成批；行数 +1；合计范围含空行；合计值不变；员工行公式跟着下移

**常见失败**：与写入 op 混批被拒后不重试；合计范围没扩（空行落在求和区间外）；插在第 9 或第 11 行

### T-02 · 删除行 `对应 XL-S-02 的删行变体`

**提示词**
```
把陈静那一行从「薪酬明细」删掉，部门汇总那边应该自己跟着变，删完告诉我变化。
```

**预期改动**
- 第 9 行消失，其余行上移；所有公式引用随之平移
- 「部门汇总」市场部行：人数 **2 → 1**、应发 36800 → **24700**、个税 2017.5 → **1720**、实发 28707.5 → **18930**
- 合计行：应发 193000 → **180900**、社保 33187.5 → **31162.5**、个税 10883.75 → **10586.25**、实发 148728.75 → **138951.25**

**通过标准**：只删 1 行；跨表 SUMIF/COUNTIF 结果自动更新；合计行 4 个数字全对

**常见失败**：删了整行但合计行范围没变（仍算到旧区间）；把陈静的行清空但没删（行数没少）；跨表汇总没变（说明汇总存了死值）

### T-03 · 插入列 `对应 XL-W-03`

**提示词**
```
在「薪酬明细」最后加一列「社保公积金(单位)」，按基本工资 35% 计算，所有员工行都要填，表头加粗。
```

**预期改动**
- N4 = `社保公积金(单位)`（加粗）；N5:N14 为公式 `=ROUND(E5*0.35,2)`
- 值：6300 / 5600 / 4550 / 9100 / 3150 / 6300 / 3850 / 3325 / 3500 / 5950

**通过标准**：10 格全为公式且逐行相对引用；数值与上表逐个相等；合计行（第 15 行）不被写入

**常见失败**：整列同值（用了 `$E$5`）；写成常量；写到 N15 顶掉合计

### T-04 · 删除列 `对应 XL-S-02`

**提示词**
```
删掉「津贴补贴」这一列（G 列）。「应发合计」引用着它，先把公式改成不含这一列，再删列。
```

**预期改动**
- 顺序：先把 H5:H14 改成 `=E5+F5`，再删 G 列（反过来会被引擎拒绝，见「加测 A-6」）
- G 列消失，原 H 列变 G 列；`应发合计` = `=E5+F5`，无 `#REF!`
- 张伟：应发 **22500**、社保 4050、应纳税所得 **13450**、个税 **1280**、实发 **17170**；合计应发 → **183100**

**通过标准**：无 `#REF!`；应发 = 基本工资+绩效；`部门汇总` SUMIF 跟随；合计 183100；调用顺序为「先改公式、后删列」

**常见失败**：先删列（会被引用预检拒绝）；留下 `#REF!` 就收工；把 `#REF!` 说成"正常"；数据错列一格

## B 块：内容与公式

### T-05 · 改值并全链重算 `对应 XL-W-01`

**提示词**
```
「薪酬明细」里张伟的基本工资从 18000 改成 20000，其他计算列让它自动更新，别手动填数。
```

**预期改动**
- E5 = 20000；H5/I5/J5/K5/M5 仍为公式，缓存值 → **25700 / 4500 / 16200 / 1830 / 19370**
- 「部门汇总」技术部应发合计：95900 → **97900**

**通过标准**：只有 E5 的值变了；下游 5 格 `data_type=='f'`；技术部合计 97900

**常见失败**：把 H5 写成 25700 常量；技术部合计仍 95900；顺手改了 E6

### T-06 · 批量追加数据行 `对应 XL-W-02`

**提示词**
```
在「薪酬明细」末尾再追加三名员工：郑凯/市场部/市场专员/9000/2000/600；何静/财务部/出纳/8500/1500/500；马超/运营部/运营专员/9500/2000/500。公式列照上面的写法补上。
```

**预期改动**
- 新增 3 行（第 15–17 行），合计行下移到第 18 行
- 三行实发：**9327.5 / 8438.75 / 9586.25**
- 合计：应发 → **227100**、实发 → **176081.25**

**通过标准**：3 行 × 10 个字段全对；公式列都是公式且引用本行；合计行下移且范围含新行

**常见失败**：覆盖合计行；公式全指向第 5 行；新行数字被写成文本（左对齐、无法求和）

### T-07 · 整列公式填充 `对应 XL-W-03 / XL-Q-02`

**提示词**
```
把「社保公积金(单位)」这一列（N5 到 N14）一次性填满公式，别一格一格写。
```

**预期改动**
- N5:N14 一次性写入，全部 `=ROUND(E{行}*0.35,2)` 形态
- 值 6300 / 5600 / 4550 / 9100 / 3150 / 6300 / 3850 / 3325 / 3500 / 5950

**通过标准**：op 数 ≤2（一条 `fill_range`）；10 格全为公式；总工具调用 ≤5 次

**常见失败**：10 次 `set_formula`（慢且易超批预算）；只填第一行；引用写成绝对地址

### T-08 · 查找替换（只动文本）`对应 XL-W-07`

**提示词**
```
把「薪酬明细」里的「技术部」全部改成「研发部」，数字和公式不要动，改完提醒我哪里可能对不上。
```

**预期改动**
- C5:C8 四个单元格变「研发部」；E 列数值、H 列公式原样
- agent 主动提示：「部门汇总」A4 仍写「技术部」，SUMIF 会失配，需要同步改

**通过标准**：只替换 4 格文本；公式零改动；主动报出跨表失配风险

**常见失败**：公式里 `"技术部"` 被替换导致数值变化却不说明；把数字当文本替换；不回报告风险

## C 块：排序、筛选、去重、工作表

### T-09 · 多关键字排序 `对应 XL-S-04`

**提示词**
```
按部门升序、同部门内按「实发合计」从高到低排序，表头不参与，合计行留在最后，整行一起动。
```

**预期改动**
- 部门分组稳定；组内实发降序：技术部 **25730(刘洋) > 18130(张伟) > 16170(李娜) > 12837.5(王强)**；市场部 **18930 > 9777.5**；运营部 **17110 > 10115**
- 合计行仍在最后，合计不变（193000 / 148728.75）

**通过标准**：抽查任意一行"姓名-部门-基本工资-实发"四元组仍匹配原表；公式随行移动且引用本行

**常见失败**：只排一列造成行撕裂（张伟配上别人的金额）；合计行被卷进排序；公式列错位

### T-10 · 双条件筛选 `对应 XL-S-05`

**提示词**
```
给表头加自动筛选，只留技术部且实发合计大于 20000 的行；然后再改成技术部或市场部。
```

**预期改动**
- 第一轮：可见 **1 行 = 刘洋（25730）**（张伟 18130 不满足）
- 第二轮（OR）：可见 **6 行** = 技术部 4 + 市场部 2

**通过标准**：命中行数与上表一致；`and`/`or` 切换生效；清除筛选后 10 行全可见

**常见失败**：条件列错位（拿部门值比金额）；and/or 反了；报"2 人（张伟、刘洋）"——张伟 18130 并不满足

### T-11 · 删除重复项 `对应 XL-S-07`

**前置**：先把第 5 行整行复制成两行重复数据（第 15、16 行），并临时移走合计行

**提示词**
```
表里可能有重复录入，帮我删掉完全重复的行，保留第一次出现的，删之前告诉我影响。
```

**预期改动**
- 删除 **2 行**，剩 10 行员工数据；首次出现的那条保留
- 删除前提示不可逆（可用版本回退），删除后报出删除数量

**通过标准**：删除数 = 2；剩余 10 行与基线一致；合计行未被误删

**常见失败**：按单列判重误删（同名不同薪被当重复）；把合计行当重复删掉；混批被拒后谎报成功

### T-12 · 工作表增改移 `对应 XL-S-03`

**提示词**
```
把「部门汇总」改名为「部门成本汇总」，再复制一份叫「汇总副本」放最后，另外把「编制说明」挪到最前面。
```

**预期改动**
- 表序：`编制说明` → `薪酬明细` → `部门成本汇总` → `汇总副本`
- 副本内容 = 基线；跨表引用若存在，同步为 `部门成本汇总!`

**通过标准**：4 个表名与顺序正确；副本数值与基线一致；无 `#REF!`

**常见失败**：改名后公式失配；副本与原表编辑互相串（同一 sheetId）；顺序不对
