# 新建工作区 Agent 改 PPT · 测试提示词清单

> 只测「提示词 → Agent 是否真的改对了 PPT」。不涉及代码改动。
> 用法：新建一个工作区 → 以**可编辑**方式打开一份 PPT → 逐条把下面的提示词粘贴给 Agent。

---

## 0. 准备

**文件**：任选一份 ≥5 页、含封面 / 目录 / 表格的 `.pptx`。

> 想要标准样张：远端 `feat/doc-office@f9501dc4` 里有 `test/fixtures/pptx-agent/PPT测试_2026年Q3经营回顾.pptx`（9 页，带隐藏页和同名标题两个坑），`git show f9501dc4:...` 取出即可。

**先做两件事**：

1. **复制一份副本**再打开——后面的提示词会真的改文件，别在原稿上测。
2. 打开后确认界面右下角/标题栏没有"只读"标记。只读打开时 Agent 的所有编辑都会被拒（这是保护，不是 bug）。

**判定口径**（每条都按这三档记）：

- ✅ 改对了，且 Agent 的描述与文件实际状态一致
- ⚠️ 改了一部分 / 样式有偏差
- ❌ 没改、改错，或**声称成功但实际没生效**（这一档最严重，会误导用户）

---

## 1. 探底：它知不知道自己在改什么

**P-01**
```
先别改，读一下这份 PPT，告诉我一共几页，每页主要写了什么。
```
> 看：页数对不对；有没有编造不存在的页。

**P-02**
```
第 2 页有哪些元素？把文字内容列给我。
```
> 看：是否读了文件才回答，而不是靠猜。

**P-03**
```
这份 PPT 现在是什么尺寸？16:9 还是 4:3？
```
> 看：会不会答"不知道"却继续改。

---

## 2. 文字（最常用的入口）

**P-04**
```
把封面标题改成「2026 年第三季度经营回顾」。
```
> 看：只改了标题，副标题没动；文字没有多余引号或空格。

**P-05**
```
把封面副标题里的 2026 改成 2027，字体大小和颜色别变。
```
> 看：字号、颜色是否保持原样（常见坑：整段重建导致样式丢失）。

**P-06**
```
第 2 页「目录」这两个字加粗，其他不动。
```
> 看：只有这两个字变粗，不是整行。

**P-07**
```
把整份 PPT 里的「季度」都换成「Q3」。
```
> 看：是不是一次全稿替换；表格里的文字有没有一起换。

**P-08**
```
第 2 页那三条列表的字号统一成 20pt，标题保持不动。
```
> 看：标题有没有被误伤。

**P-09**
```
第 1 页副标题改长一点：「Fiscal Year 2026 全年经营复盘与 2027 财年规划预告」，别让字跑出页面。
```
> 看：长文本有没有溢出或截断。

## 3. 样式与外观

**P-10**
```
把封面那页背景改成浅灰蓝色。
```
> 看：是改页面背景，还是盖了个矩形上去。

**P-11**
```
第 2 页的标题文字改成深蓝色。
```
> 看：只改文字颜色，没动背景。

**P-12**
```
除封面和最后一页，其他页的标题统一成 28pt 加粗、颜色 #1F3A5F。
```
> 看：有没有漏页或多改封面。

**P-13**
```
第 3 页那张图（或那个形状）加一圈 1.5pt 的浅灰边框。
```
> 看：是真边框，还是外面套了根线。

**P-14**
```
给第 3 页那个形状加一点柔和的外阴影。
```
> 看：不支持时会不会如实说，而不是假装做了。

## 4. 位置与层级

**P-15**
```
把第 3 页那张图挪到右下角，离页边留一点距离。
```
> 看：位置对不对；图片有没有被拉伸变形。

**P-16**
```
把第 3 页那张图缩小到原来一半，中心位置别动。
```
> 看：是不是只改了宽高导致图跑到左上角。

**P-17**
```
第 3 页那两个元素顶部对齐。
```
> 看：是不是两个都动了。

**P-18**
```
把第 3 页那张图放到文字下面。
```
> 看：层级对不对；有没有用"删掉再插一张"的粗暴办法。

## 5. 页面与结构

**P-19**
```
在第 4 页后面插一页「下一步计划」，版式跟其他内容页保持一致。
```
> 看：插的位置对不对（不是加在最后）；版式是不是空白页。

**P-20**
```
把最后那页「Thank you / 谢谢观看」挪到目录页后面。
```
> 看：页序对不对，各页内容有没有错乱。

**P-21**
```
删掉「目录」那页。
```
> 看：删的是不是这一页；删完有没有复述结果。

**P-22**
```
最后一页复制一份，内容跟「关键指标」那页一样。
```
> 看：是复制页面，还是新建空白页再堆元素。

**P-23**
```
把「关键指标」那页先隐藏，别删。
```
> 看：是隐藏（放映不出现、页数不变）还是直接删了。

**P-24**
```
把整份改成 4:3。
```
> 看：改完元素有没有被裁掉一半。

## 6. 表格与内容

**P-25**
```
第 4 页表格的表头第一格改成「区域」。
```
> 看：只有那一格变了，不是整表重建。

**P-26**
```
第 4 页表格第一列加宽一点，行高统一 0.4 英寸。
```
> 看：是不是只改了一列或一行。

**P-27**
```
第 4 页表格最后加一行「其他」，金额填 0。
```
> 看：行数 +1；样式有没有沿用上一行。

**P-28**
```
第 4 页表格里的数字如果有合计，帮我把合计跟上面几行核对一下。
```
> 看：会不会真的去算，还是敷衍"已核对"。

**P-29**
```
给第 4 页加一句备注：数据待财务确认。
```
> 看：是写进演讲者备注，还是塞进正文。

## 7. 故意刁难（这组最能暴露问题）

**P-30**
```
把第 12 页的标题改一下。
```
> 文件只有 5~9 页。看：是明确说"没有第 12 页"，还是自己找了个页面改。

**P-31**
```
把标题改一下。
```
> 用在有一页含两个标题的文件上。看：是先问清哪个，还是随便改一个。

**P-32**
```
把每一页的标题都加粗、字号加大 2pt。
```
> 页数多时会超过单次批量上限。看：会不会自动拆成几批，还是做一半就说完成。

**P-33**
```
先试运行一下把封面标题改掉，别真的落盘。
```
> 看：是否真的不落盘（改完再读一次确认原文没变）。

**P-34**
```
你们能改 PPT 吗？能改哪些东西？
```
> 看：会不会夸大能力（后续改不动就尴尬）。

---

## 8. 一条端到端（最后跑）

**P-35**
```
帮我把这份 PPT 收拾一下：
封面标题改成「2026 年第三季度经营回顾」；
除封面和最后一页，每页标题统一 28pt 加粗深蓝；
最后加一页「下一步计划」，正文写三条待办；
改完自己再读一遍，确认都改对了再告诉我。
```
> 看：四件事是否都完成；中途报错是否续做；**最后有没有真的自检**（而不是直接宣布成功）。

## 11. 出问题时先自查这四条

| 现象 | 先查什么 |
|---|---|
| 所有编辑都被拒 | 文件是不是**只读**打开的；界面里是不是有**未保存**修改（先 `⌘S`） |
| 报"元素不存在" | 它是不是还在用上一轮的元素 id（每次编辑后 id 会变，应该重新读一次） |
| 改完样式变了样 | 提示词里是不是只说了改字（模型重建文本时容易丢字号/颜色） |
| 长任务停在"达到输出上限" | 设置里「单次输出上限」调大；或直接点「继续」 |
