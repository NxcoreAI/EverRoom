## 11. 出问题先看这四条

| 现象 | 先查什么 |
|---|---|
| 所有编辑都被拒 | 是不是**只读**打开；界面里有没有未保存修改（先 ⌘S） |
| 报「元素不存在」 | 是不是还在用上一轮的元素 id（每次编辑后 id 会变，应重新读一次） |
| 改完字号/颜色变了 | 提示词只说改字，模型重建文本时丢了样式 |
| 长任务停在「达到模型输出上限」 | 设置里「单次输出上限」调到 ≥16384；或直接点「继续」 |

## 12. 这份稿子特有的两个坑

1. **第 6 页是「左文右图」混排**：文字块和图表挤在同一行，改字号或改图宽很容易把图挤到换行。P-18、P-29 就是专门测这个。
2. **全篇是「一句标题 + 若干卡片」的版式**：卡片都是独立形状、**没有组合**。所以「把三张卡一起往下挪」这类要求，考验它是一张一张改（易漏）还是先组合（groupElements）再动。
