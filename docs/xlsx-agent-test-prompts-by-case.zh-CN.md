### XL-D-06 · 汇总表回填活公式（文本金额 → SUMIF） `P1`

```
帮我修「部门成本汇总」这张表：它的金额现在是文本（'110,900.00' 这种），既不联动明细也不能可靠求和，请全部改成引用「薪酬明细」的活公式。

先读一遍再动：「薪酬明细」C 列=部门，G 列=应发合计，H 列=社保公积金(个人)，J 列=个人所得税，L 列=实发合计；数据在第 5–16 行（12 人），合计在第 17 行。

1. 汇总表部门清单与明细一致（6 个：财务部、人事部、市场部、产品部、研发部、运营部），少「产品部」要补齐；部门行从第 4 行开始，合计行紧随其后。
2. B 列人数 =COUNTIF(薪酬明细!$C$5:$C$16,$A4)；C 列应发 =ROUND(SUMIF(薪酬明细!$C$5:$C$16,$A4,薪酬明细!$G$5:$G$16),2)；D 列社保 =ROUND(SUMIF(薪酬明细!$C$5:$C$16,$A4,薪酬明细!$H$5:$H$16),2)；E 列个税 =ROUND(SUMIF(薪酬明细!$C$5:$C$16,$A4,薪酬明细!$J$5:$J$16),2)；F 列实发 =ROUND(SUMIF(薪酬明细!$C$5:$C$16,$A4,薪酬明细!$L$5:$L$16),2)。用区域填充一次生成，不要逐格写。
3. 合计行用 SUM 覆盖部门行；金额千分位两位小数；表头加粗。
4. 不要用「公式转数值」，金额必须是数值公式。
5. A11 那行「两表实发合计」整行删掉；「汇总副本」整张工作表删掉。
```
