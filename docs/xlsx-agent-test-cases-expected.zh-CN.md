## A 组：读取与理解（XL-R）

### XL-R-01 · 工作簿总览 `P0`

**提示词**
```
看一下这份财务报表的结构：有几个工作表、每个表大概多少行多少列、现在选中哪个表。
```

**预期结果**
- Agent：调用 `sheets_agent_read`（底层 `get_workbook_context`），1–2 次调用，不整表 `read_range`
- 文件：**零改动**，版本号不变
- 回复：3 个工作表 `薪酬明细` / `部门汇总` / `编制说明`；`薪酬明细` 约 17 行 × 13 列（报 A1:M17 或 A4:M17 都可）

**不通过**：漏报 `编制说明`；把 `max_row=17` 当"17 行员工数据"；调用超过 5 次；版本号变化

### XL-R-02 · 精确区域读取 `P0`

**提示词**
```
把「薪酬明细」前 5 行的姓名、部门、基本工资、实发合计读出来，用紧凑表格给我。
```

**预期结果**
- Agent：`read_range` 精确区域（A5:A9 / C5:C9 / E5:E9 / M5:M9 或一次整块再筛列），≤3 次
- 文件：零改动
- 回复：5 行表格——张伟/技术部/18000/18130、李娜/技术部/16000/16170、王强/技术部/13000/12837.5、刘洋/技术部/26000/25730、陈静/市场部/9000/9777.5；实发给的是**算好的数**，不是 `=H5-I5-K5-L5`

**不通过**：把公式串贴给用户；行列错位一格；返回 `None` 却说空

### XL-R-03 · 稀疏单格读取 `P1`

**提示词**
```
「编制说明」第 3 条和第 6 条分别写了什么？顺便看一下 A1 是什么。
```

**预期结果**
- Agent：`read_cells`（按地址集合），≤2 次
- 文件：零改动
- 回复：A3 ≈「本表为示例财务报表，数据为演示用虚构数据……」（第 3 条行号按实际内容对齐：即"社保/实发"两条中的第 6 条为「实发合计 = 应发合计 − 社保 − 个税 − 其他扣款」）；A1 = `编制说明`

**不通过**：编造说明文字；整表读一遍再说；把 A1 报成标题以外的值

### XL-R-04 · 统计聚合 `P0`

**提示词**
```
「薪酬明细」里技术部的实发合计总额是多少？全公司个税最高的是谁、多少钱？
```

**预期结果**
- Agent：`aggregate_range` 或读区域后求和/取最大值，不逐格读
- 文件：零改动
- 回复：技术部实发合计 **72867.5**；个税最高 **刘洋 3420**；并说明口径（是否含合计行）

**不通过**：把合计行重复计入（约 148728.75 或翻倍）；数字在文件里找不到；用"大约 7 万"糊弄

### XL-R-05 · 跨表查找 `P1`

**提示词**
```
在整个工作簿里找出所有出现「技术部」的单元格，按工作表分组列出来。
```

**预期结果**
- Agent：`find_cells`（可跨表或分表查）
- 文件：零改动
- 回复：`薪酬明细` C5、C6、C7、C8 共 4 处 + `部门汇总` A4 共 1 处 = **5 处**，坐标带表名

**不通过**：只查活动表（报 4 处）；坐标缺表名；把 `技术部` 匹配到不相干文本

### XL-R-06 · 格式读取 `P2`

**提示词**
```
「薪酬明细」里金额列现在用的是什么数字格式？表头行是加粗的吗？
```

**预期结果**
- Agent：`read_formats`
- 文件：零改动
- 回复：如实说明当前格式（基线为 `General`，无千分位）与表头是否加粗（基线：第 4 行未加粗）；不确定时说明"读到的就是 General"

**不通过**：凭经验答"应该是 #,##0.00"；答"看不出"；把格式和值混为一谈

### XL-R-07 · 公式依赖审计 `P0`

**提示词**
```
「薪酬明细」M5 这个格的公式引用了哪些单元格？反过来，E5 被哪些公式用到？
```

**预期结果**
- Agent：`trace_precedents` + `trace_dependents`
- 文件：零改动
- 回复：M5 ← H5、I5、K5、L5；H5 ← E5、F5、G5；E5 的从属至少包含 H5、I5、M5；坐标带表名

**不通过**：只报一层（说 M5 只依赖 H5）；漏掉 I5/K5/L5；把 E5 的从属说成"没有"

### XL-R-08 · 特性读取 `P1`

**前置**：先跑 XL-F-06（条件格式）、XL-D-01（数据验证）、XL-V-06（批注）

**提示词**
```
这份表现在有哪些条件格式、数据验证和批注？分别在哪张表哪些区域？
```

**预期结果**
- Agent：`read_sheet_features`
- 文件：零改动，且**不清除**既有规则
- 回复：条件格式 2 条（K5:K14 大于 1000 红底、M5:M14 数据条）、数据验证 2 条（C5:C14 下拉 5 项、E5:E14 >0）、批注 1 条（表头）

**不通过**：答"没有"；把表格样式当条件格式；读取动作改了文件

## B 组：内容写入与公式（XL-W）

### XL-W-01 · 单格改值 + 全链重算 `P0`

**提示词**
```
把「薪酬明细」张伟的基本工资从 18000 改成 20000，其他自动算的列跟着更新。
```

**预期结果**
- Agent：先 `read_range` 定位 → 一次 `propose_operations([set_cell E5])`；不手算 H/I/J/K/M
- 文件：E5=20000；H5/I5/J5/K5/M5 **仍是公式**，缓存值分别 **25700 / 4500 / 16200 / 1830 / 19370**；`部门汇总` C4 技术部应发合计 **95900 → 97900**
- 回复：说明"只改了 E5，下游 5 列公式自动重算"，给出坐标与新值；版本 +1

**不通过**：把 H5 写成 25700 常量；技术部合计仍 95900（存了死值）；改了 E6 或别处；只改 E5 但下游值没更新

### XL-W-02 · 追加新行并沿用公式 `P0`

**提示词**
```
在「薪酬明细」最后一名员工下面加一行：孙悦、技术部、数据工程师、基本工资 15000、绩效 3000、津贴 800，公式列照上面的写法。
```

**预期结果**
- Agent：`insert_rows`（单批）或直接写第 15 行，公式列用 `set_formula` / `fill_range` 平移
- 文件：第 15 行 = 孙悦/技术部/数据工程师/15000/3000/800；H15=18800、I15=3375、J15=10425、K15=832.5、M15=14592.5（**公式形态**）；原合计行下移到第 16 行且 `SUM` 范围含第 15 行，合计应发 **193000 → 211800**、实发合计 **148728.75 → 163321.25**
- 回复：说明插入位置与合计范围变化

**不通过**：覆盖掉合计行；公式仍引用第 5 行；合计未含新行（仍 193000）；数值列被写成文本

### XL-W-03 · 批量公式填充 `P0`

**提示词**
```
给「薪酬明细」新增一列「社保公积金(单位)」，按基本工资的 35% 计算，整列填满（含所有员工行），表头加粗。
```

**预期结果**
- Agent：`set_cell`(N4 表头) + `fill_range`(N5:N14, `=ROUND(E5*0.35,2)`) + `format_range`(N4 加粗)，op 数 ≤4，**不是** 10 次 `set_formula`
- 文件：N4=`社保公积金(单位)` 加粗；N5:N14 全为公式（逐行相对引用）；值 = 6300 / 5600 / 4550 / 9100 / 3150 / 6300 / 3850 / 3325 / 3500 / 5950
- 回复：说明用了 `fill_range` 一次填充，列位置 N

**不通过**：整列同值（`$E$5` 绝对引用）；写成常量 6300…；逐格 10 次调用；写到 N15（合计行）

### XL-W-04 · 区域一次性写入 `P1`

**提示词**
```
在「编制说明」下面的空行追加一个 3 列的说明块：日期、修订人、修订内容，先填 3 行示例数据。
```

**预期结果**
- Agent：一条 `set_range`（3×3）
- 文件：目标 9 格内容与给定数据完全一致；上方 10 条说明文字不动；日期若写入日期值应带日期格式（或纯文本一致）
- 回复：给出写入区域坐标（如 A12:C14）

**不通过**：9 次 `set_cell`；覆盖原说明；日期变序列号且无格式

### XL-W-05 · 区域复制（公式平移）`P1`

**提示词**
```
把「薪酬明细」A4:M14 复制到新工作表「明细备份」，公式保持，公式里的引用指向备份表自己的数据。
```

**预期结果**
- Agent：`add_sheet` + `copy_range`（或 `duplicate_sheet` 等价路径）
- 文件：新表 11 行 × 13 列与源一致；备份表 H5 公式 = `=E5+F5+G5`（**本表相对引用**）；数值与基线一致；`薪酬明细` 未变
- 回复：说明新建了哪张表、公式引用是否本地化

**不通过**：复制成常量；公式仍写 `薪酬明细!`；源表被改动；只复制了值没复制格式另说但不扣分

### XL-W-06 · 公式转数值 `P1`

**提示词**
```
把「部门汇总」里的公式全部变成当前算出来的数值，公式清掉，格式保留。
```

**预期结果**
- Agent：`convert_to_values`（B4:F8）
- 文件：B4:F8 从公式变数值，值 = 基线（4/95900/16425/6607.5/72867.5 …）；字体/数字格式不变；`薪酬明细` 未受影响
- 回复：说明转换区域与"不可逆（可用版本回退）"

**不通过**：值变 0 或 None（用了未重算缓存）；格式丢失；连带把明细表也转了

### XL-W-07 · 文本查找替换 `P1`

**提示词**
```
把「薪酬明细」里所有「技术部」改成「研发部」，别动数字和公式。
```

**预期结果**
- Agent：`find_replace`（限定 C 列或整表）
- 文件：C5:C8 = 研发部；E 列数值、H 列公式原样；`部门汇总` A4 若不在替换范围仍是"技术部"，且 **agent 主动提示**跨表引用会失配
- 回复：说明替换了 4 个单元格 + 提醒汇总表需同步

**不通过**：公式里的 `"技术部"` 被顺手改掉而未说明；数字被当文本替换；改了 A4 却没告知

### XL-W-08 · 区域清空（仅内容）`P2`

**提示词**
```
把「编制说明」第 8–10 条清空内容，但保留单元格格式。
```

**预期结果**
- Agent：`clear_range`（仅内容，A8:A10）
- 文件：A8:A10 为 `None`；格式（字体/边框/数字格式）保持；A1:A7 不动
- 回复：说明只清内容未清格式

**不通过**：整表清空；连格式一起清（那是 `clear_formats`）

## C 组：格式与数字格式（XL-F）

### XL-F-01 · 表头样式 `P0`

**提示词**
```
「薪酬明细」第 4 行表头：加粗、浅灰底、居中、自动换行；列宽调到不溢出。
```

**预期结果**
- Agent：一条 `format_range`(A4:M4) + `set_col_width`
- 文件：A4:M4 13 个单元格全部 `bold=True`、浅灰填充、`horizontal='center'`、`wrap_text=True`；列宽 ≥12；第 5 行数据行样式不变
- 回复：说明作用区域是 A4:M4，共 13 格

**不通过**：只改了 A4（选区变单格）；整表加粗；列宽没变；改到第 5 行

### XL-F-02 · 数字格式三件套 `P0`

**提示词**
```
金额列用千分位两位小数；「社保公积金(个人)」用同样格式；标题下面的日期行改成 yyyy-mm-dd。
```

**预期结果**
- Agent：`format_range.numberFormat`
- 文件：E5:M15 `number_format == '#,##0.00'`；A2 文本行保持文本（或按需设日期段）；**存储值不变**（张伟仍 18000，不是 "18,000.00" 字符串）
- 回复：列出设置的格式串

**不通过**：把值转成字符串；格式写成 `0.00`（丢千分位）；整表套成日期格式

### XL-F-03 · 财务会计格式（负数/零值）`P1`

**提示词**
```
「实发合计」列用会计格式：人民币符号、负数红色括号、零显示成短横线。
```

**预期结果**
- Agent：`format_range.numberFormat`，locale 锁定三段式（如 `[$$-409]#,##0.00;[Red]([$$-409]#,##0.00);"-"`）
- 文件：M5:M15 格式串含 `[Red]` 与零值段 `"-"`；数值仍 18130 等；Excel 打开显示 `¥18,130.00`
- 回复：给出使用的格式串并说明 locale

**不通过**：只改字体颜色；出现 `¤` 乱码或 `$` 与 `¥` 混用；值被改写

### XL-F-04 · 边框线型 `P1`

**提示词**
```
「部门汇总」表头行加双线外框，数据区内部用细虚线网格。
```

**预期结果**
- Agent：`format_range.border {type, style}`
- 文件：A3:F3 外框 `border.style == 'double'`；A4:F8 内部网格 `'dashed'`；无空白区域被加框
- 回复：说明线型与作用区域

**不通过**：全用实线；边框扩到整张表；只加了外框没加网格却称完成

### XL-F-05 · 合并单元格 `P2`

**提示词**
```
把标题行 A1:M1 合并居中，「编制说明」的 A1 不用动。
```

**预期结果**
- Agent：`merge_cells` + `format_range` 居中
- 文件：`薪酬明细` 合并区 = `A1:M1`，文本「月度薪酬费用财务报表」仍在 A1；其余工作表合并区为 0
- 回复：说明合并范围

**不通过**：合并到 `编制说明`；合并后文本丢失；重复合并报错后仍称成功

### XL-F-06 · 条件格式 `P1`

**提示词**
```
给「薪酬明细」个税列加规则：大于 1000 的标浅红底；再给实发合计列加数据条。
```

**预期结果**
- Agent：先 `read_sheet_features`，再 `add_conditional_format` 两条（number + dataBar）
- 文件：K5:K14 一条 `cellIs greaterThan 1000` 规则（命中 张伟1520/李娜1030/杨帆1720/徐丽1265/刘洋3420 共 5 格）；M5:M14 有 dataBar；原规则未被清
- 回复：说明规则条件与作用区域

**不通过**：清掉已有规则；阈值写成 `>=1000`/`>10000`；只对 K5 生效

### XL-F-07 · 主题与配色 `P2`

**提示词**
```
把这份表换成「森林」主题，再把配色换成暖色。
```

**预期结果**
- Agent：`set_theme {theme:'forest'}` / `{colors:'warm'}`
- 文件：主题色写入工作簿样式，保存重开后表头/图表配色仍生效；无效 id 时报错并列出可用 id
- 回复：说明实际应用的主题 id

**不通过**：说改了但文件无变化（静默无效）；把非导入 xlsx 当目标却不报"需要导入的 xlsx"

### XL-F-08 · 行列尺寸与隐藏 `P2`

**提示词**
```
表头行高调到 30，把「津贴补贴」列隐藏再取消隐藏。
```

**预期结果**
- Agent：`set_row_height` + 列隐藏（`hidden:true` → `false`）
- 文件：第 4 行 `height≈30`；G 列最终 `hidden=False`；数据零改动（G5 仍 1200）
- 回复：说明两步都做了

**不通过**：隐藏后无法恢复；把列宽当行高；数据被改动

## D 组：结构与工作表（XL-S）

### XL-S-01 · 插入行（公式范围联动）`P0`

**提示词**
```
在「薪酬明细」第 10 行前插一行空行，合计行的求和范围要能覆盖它。
```

```
帮我审一下这张表的公式：个税公式是不是对的（2026 年 10 月按月度预扣，起征点 5000）、社保口径一致吗、有没有引用错行。给出问题清单并修好能确定的错误。
```

**预期结果**
- Agent：`trace_precedents` / `read_formats` / `read_range` 逐个审计，再 `propose_operations` 修
- 回复：问题清单具体到单元格，且**结论正确**——
  - 个税：`=ROUND(IF(J<=0,0,IF(J<=3000,J*3%,IF(J<=12000,J*10%-210,…))))` 七档，与月度税率表一致 ✅
  - 起征点：J 列 `=MAX(0,H-I-5000)` 已扣 5000，K 列未重复扣减 ✅
  - 社保：统一 `基本工资×22.5%`（养老 8% + 医疗 2% + 失业 0.5% + 公积金 12%），口径一致 ✅
  - 行引用：H/I/J/K/M 均引用本行，无错行 ✅
- 文件：对**确定性错误**（如发现某行公式偏移/漏行）修正并给出前后对照；对正确公式不动

**不通过**：臆造问题、乱改正确公式；泛泛而谈"看起来没问题"；发现问题却不给单元格坐标
