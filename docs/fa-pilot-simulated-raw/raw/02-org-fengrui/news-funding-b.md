# 工业质检赛道再获大额融资：棱镜检测 B 轮 2 亿落定

> 来源：投中网（编辑：李文）　发布：2026-03-20 08:15
> 注：综合棱镜检测官方通稿及公开信息整理。

工业视觉检测公司棱镜检测近日宣布完成 B 轮融资，规模 2 亿元人民币，由远帆资本领投。

本轮资金将用于产能扩张与出海业务。棱镜检测成立于 2018 年，深耕锂电池、汽车零部件行业的视觉检测设备。
